------

## 二、Agent 层依赖（精简）

只引入 4 个包，**不引入** `langchain` 全量包：

| 包                    | 用途                                                       |
| --------------------- | ---------------------------------------------------------- |
| `langgraph`           | 状态图编排、条件路由、子图、流式事件、Checkpointer         |
| `langchain-core`      | LLM 抽象、Prompt 模板、Tool 定义、Retriever 接口、Document |
| `langchain-openai`    | 兼容 DeepSeek/Qwen 的 OpenAI 格式 API 调用                 |
| `langchain-community` | Chroma / Neo4j 集成                                        |

## 四、各节点职责

| 节点             | 职责                                                         | 使用的 LangChain 组件              |
| ---------------- | ------------------------------------------------------------ | ---------------------------------- |
| `query_analysis` | 意图识别（code/doc/graph/mixed/chitchat）、查询改写、关键词提取 | ChatModel + with_structured_output |
| `router`         | 根据 intent 条件路由到对应子图                               | Conditional Edge                   |
| `code_agent`     | 代码向量检索 + BM25 + AST 过滤                               | Retriever + Tool                   |
| `doc_agent`      | 文档向量检索 + BM25 + 图片/表格检索                          | Retriever + Tool                   |
| `graph_agent`    | Cypher 查询 + 社区摘要                                       | Neo4j Tool                         |
| `aggregator`     | 多路结果合并、去重、Reranker 精排取 Top-K                    | CrossEncoder                       |
| `generator`      | 组装上下文 → LLM 流式生成回答                                | ChatModel + PromptTemplate         |
| `post_process`   | 提取引用来源、格式化图片/表格占位符                          | OutputParser                       |

## 六、LangGraph 特性使用

| 特性                 | 用途                                         |
| -------------------- | -------------------------------------------- |
| `StateGraph`         | 定义主流程有向图                             |
| `Conditional Edge`   | router 根据意图分发                          |
| `SubGraph`           | 三个子 Agent 作为可复用子图嵌入              |
| `Send API`           | 子图内并行执行多路检索 (fan-out/fan-in)      |
| `astream_events`     | 流式输出 token + 节点事件 → 对接 FastAPI SSE |
| `AsyncPostgresSaver` | Checkpointer 持久化对话状态、支持断点续跑    |
| `interrupt_before`   | 可选：人机确认（检索结果确认后再回答）       |

## 九、与 FastAPI 对接方式

```
前端 ──POST /chat/completions──▶ FastAPI
                                    │
                                    ▼
                          graph.astream_events()
                                    │
                                    ▼
                          SSE 事件流 (逐 token)
                                    │
                          ┌─────────┼─────────┐
                          ▼         ▼         ▼
                     type:token  type:node  type:citations
                     (逐字输出)  (进度)     (引用来源)
```

| SSE 事件类型 | 触发时机               | 前端处理         |
| ------------ | ---------------------- | ---------------- |
| `token`      | `on_chat_model_stream` | 逐字追加到回答区 |
| `node_done`  | 各节点完成             | 展示进度指示器   |
| `citations`  | `post_process` 完成    | 渲染引用卡片     |
| `[DONE]`     | 流结束                 | 关闭连接         |

## 十六、关键设计决策总结

| 决策点             | 选择                           | 理由                                             |
| ------------------ | ------------------------------ | ------------------------------------------------ |
| Agent 框架         | LangGraph（非 AutoGen/CrewAI） | 有向图控制流，适合 RAG 管道，非多 Agent 对话场景 |
| LangChain 引入范围 | 仅 core + openai + community   | 避免全量包依赖膨胀                               |
| 子图 vs 单图       | 子图                           | 各检索路径独立可测试、可复用                     |
| 并行检索           | LangGraph Send API             | 原生 fan-out/fan-in，无需额外并发库              |
| 流式输出           | astream_events → SSE           | 原生支持 token 级 + 节点级事件                   |
| 状态持久化         | AsyncPostgresSaver             | 复用已有 PG，支持断点续跑                        |
| LLM 调用           | langchain-openai (ChatOpenAI)  | DeepSeek/Qwen 均兼容 OpenAI 格式                 |
| 检索器             | 自定义 BaseRetriever 子类      | 统一接口，可被 LangGraph 节点直接调用            |
