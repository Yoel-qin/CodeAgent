## 项目定位

**CodeRAG**（`D:\project\CodeRagAgent`）：面向大型 Java 代码库的 RAG 智能知识库。融合语义向量 + GNN 图向量 + 三阶段精排 + GraphRAG 社区摘要，9 个 LangGraph Agent，支持增量更新与代码回滚。设计文档在仓库根 `*.md`。

## 技术栈

- **后端**：FastAPI + Uvicorn + sse-starlette（SSE）；Phase 7 才引 LangGraph。包管理 uv。
- **前端**：React18 + TS + Vite + AntD5 + Zustand + React Router6。包管理 pnpm。
- **数据**：PostgreSQL 16（真相源）/ Milvus（向量）/ Elasticsearch（BM25）/ Redis 7 / MinIO。
- **模型**：嵌入走 API（硅基流动 BGE-M3，1024d）；LLM 走 API（DeepSeek-v4-flash）。**不用本地 GPU**。

## 架构（2026-07-25 调整）

**后端 + 前端 + model_server 在本地 host 跑；Docker 只跑基础设施**（postgres / redis / minio / elasticsearch / etcd / milvus / attu）——为降 Docker 内存。`docker-compose.yml` 已改为 infra-only（无 backend/frontend/nginx/model_server）。infra 端口全映射到 host，本地 backend 经 localhost 连接（根 `.env`：PG 5432 / Redis 6379 / MinIO 9000 / ES 9200 / Milvus 19530）。

运行方式：
```bash
docker compose up -d                                          # 基础设施
cd backend && uv run uvicorn app.main:app --reload --port 8000
cd frontend && pnpm dev                                        # http://localhost:5173
```

- **范围**：纵向 MVP 优先（Phase 0 + Phase 1 + 前端 P0 打通最短闭环），高级能力逐 Phase 加层。

## 关键坑（排错参考）

- **elasticsearch-py 9.x 与 ES 8.11 服务器不兼容**（Accept 版本报错）→ 锁 `elasticsearch>=8.11,<9`。
- **Milvus 必须配 `MINIO_ACCESS_KEY_ID/SECRET` 匹配 MinIO 的 `MINIO_ROOT_USER/PASSWORD`**，否则 crashloop（反复重启）。
- **`asyncio.to_thread` 传 keyword-only 参数（如 `top_k`）会 TypeError 且被 try/except 静默吞掉** → 把 `top_k` 改成位置参数（`es_client.search` / `milvus_client.search`）。
- **硅基流动 `/rerank` 无 `bge-reranker-base`**（HTTP 400 Model does not exist），只有 `BAAI/bge-reranker-v2-m3` → 粗排模型（`RERANKER_COARSE_MODEL`）留空走单阶段精排；精排每阶段须独立 try/except，否则粗排失败会连带把精排也吞掉（曾导致 `rerank_on=false` 静默失效）。
- **中文 Windows GBK**：`alembic.ini` 纯英文注释；脚本输出 emoji/中文需 `sys.stdout.reconfigure(encoding="utf-8")`。
- **国内 Docker**：`daemon.json` 配可用镜像源（1ms.run / xuanyuan.me / daocloud / 1panel / nju / rat.dev；旧的 aliyun/163/tencent 已失效）；etcd 用 docker.io 的 `bitnami/etcd`（原 `quay.io` 不走加速）；Git Bash 调 docker 需把 `C:\Program Files\Docker\Docker\resources\bin` 加入 PATH（否则 `docker-credential-desktop` 找不到）。
- **前端容器构建**：`pnpm-workspace.yaml`（`allowBuilds: esbuild: true`）必须 COPY 进镜像，否则 pnpm 11 把 ignored builds 当错误致构建失败。
