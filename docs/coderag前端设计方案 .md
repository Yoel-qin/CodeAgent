# RocketMQ 智能知识库 RAG 系统 — 前端设计方案

------

## 一、设计定位

这不是一个通用聊天界面，而是一个**面向 RocketMQ 代码库的工程知识工作台**。前端的核心使命是：让开发者在一个屏幕内完成"提问 → 检索 → 溯源 → 关联 → 行动"的完整闭环。

**设计原则：**

| 原则       | 说明                                         |
| ---------- | -------------------------------------------- |
| 代码优先   | 界面以代码和结构信息为主角，而非纯对话流     |
| 溯源可见   | 每个回答都能一键跳转到源码行号和文档章节     |
| 关联显性化 | 代码 ↔ 文档 ↔ 调用链的关系以图形方式直接呈现 |
| 状态可感知 | 索引状态、同步进度、回滚事件实时反馈         |

------

## 五、视觉风格建议

| 维度       | 建议                                                    |
| ---------- | ------------------------------------------------------- |
| 整体基调   | 深色工程风（类 IDE 暗色主题），符合开发者日常习惯       |
| 主色       | RocketMQ 品牌橙 (#FF6A00 系) 作为强调色                 |
| 代码区     | 等宽字体 (JetBrains Mono / Fira Code)，语法高亮         |
| 正文       | 无衬线字体，中文用系统默认 (PingFang / Microsoft YaHei) |
| 状态色     | 🟢 正常 / 🟡 同步中 / 🔴 异常 / ⚠️ 过期橙黄                 |
| 图谱节点色 | 蓝=代码类 / 绿=方法 / 黄=文档 / 红=过期                 |
| 动效       | 图谱力导向动画、检索漏斗逐级展开、面板滑入，克制不花哨  |

## 六、页面优先级与实现顺序

| 优先级 | 页面                           | 理由                       |
| ------ | ------------------------------ | -------------------------- |
| P0     | 智能问答页（含右侧上下文面板） | 核心使用场景，80% 时间在此 |
| P0     | 输入区 + Agent 选择器          | 问答入口                   |
| P1     | 代码浏览页                     | 主动探索代码结构           |
| P1     | 同步管理页（含回滚详情）       | 运维必需                   |
| P2     | 知识图谱页                     | 可视化加分项               |
| P2     | 社区总览页                     | GraphRAG 价值展示          |
| P3     | Agent 面板 + 系统监控          | 管理辅助                   |

## 七、一句话总结

**前端 = 三栏工作台（导航 + 对话主区 + 上下文面板），以"代码引用可跳转、文档引用可溯源、关联关系图形化、回滚状态可追踪"为核心体验，深色 IDE 风格 + RocketMQ 橙色强调，按 P0→P3 分四期实现。**
